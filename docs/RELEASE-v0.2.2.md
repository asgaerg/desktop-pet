# DesktopPet v0.2.2

桌面 AI 伴侣：透明置顶窗、会动的立绘、能打字也能说话，全部跑在本机。

> 相比 0.2.1，修了两个用户能直接感知的问题：
> **语音没声音**，和**全局键被我改坏了**。

## 这一版修了什么

### 语音没声音（真 bug，存在了 11 天）

症状很怪：**同一个音频文件，用别的播放器放有声音，宠物放就没声音。**

根因是内部一个字段被两件事共用：

```
麦克风采集   用这个字段接到「录音」那条路
语音播放     也用了同一个字段
```

播放时看到字段"已经有了"就跳过创建，于是**声音被接到了录音链路**上 ——
而那条路上有个"防止啸叫"的静音节点，声音进去就被吃掉了。

**所以表现是：**

| 情况 | 结果 |
|---|---|
| 没开过麦克风 | 有声音 |
| 开过麦克风（语音对话 / 按住说话） | **没声音** |

这就是为什么它时好时坏 —— 取决于你有没有开过语音。

现在采集和播放各用各的，互不干扰。

### 全局键被我改坏了（我的错）

上一版我看到配置里写着 `global_vk: 186  # F9`，觉得"值和注释对不上"
（186 其实是分号键，F9 是 120），就"修正"成了 120。

**结果语音反而不工作了。** 后来你告诉我：「改成分号，我之前都用的它」。

所以 186 不是笔误，**那就是你一直在用的键**，只是注释写错了。
现在已改回分号。

⚠️ 已知代价：分号会被全局吃掉，打字时打不出分号。你之前接受这个。

### 顺带修的两个小问题

- **麦克风设备失效时自动回退**：如果配置里选的那支麦克风被拔了/驱动重装，
  以前会静默失败（"看着在听、其实什么都没录到"），现在会回退到系统默认并提示你重选。
- **`.gitignore` 补漏**：`build/_*.txt` 原来没被忽略，我排查时的临时文件差点提交进去。

## ⚠️ 已知问题

- **全屏游戏时全局键能否用**：还没确认。分号键已经能用了，但全屏独占游戏里
  是否会被游戏抢走按键，需要实测。
- **探头旋转时仍有轻微下沉**（旧病）。这套画布 + 窗口的方案有上限，
  要序列帧动画才能根治（记在文档 §一百八十二）。
- **好奇搜索会花 API 额度**（每轮都调模型判断"还缺什么"）。
- 未签名，SmartScreen 会拦一下（更多信息 → 仍要运行）。
- 安装包要放在纯英文路径里运行（如 `C:\Temp`）。含中文的路径 NSIS 会静默失败。
- 杀软可能误报 `resources\pet\pet.exe`，加白名单即可。

## 下载

| 文件 | 说明 |
|---|---|
| `DesktopPet-0.2.2-online-setup.exe` | 安装包 |
| `DesktopPet-0.2.2-online-portable.zip` | 绿色包，解压即用 |

**不发离线版**：1.55 GB 的语音模型不跟着包走。要离线语音，
设置 → 语音 里有下载地址（`hf-mirror.com`），下完放进提示目录即可。

校验：`Get-FileHash .\DesktopPet-0.2.2-online-setup.exe -Algorithm SHA256`

## 安装

```powershell
copy .\DesktopPet-0.2.2-online-setup.exe C:\Temp\setup.exe
C:\Temp\setup.exe
```

默认装到 `%LOCALAPPDATA%\Programs\DesktopPet`，不需要管理员权限。
绿色版解压到**可写**目录（别放 `C:\Program Files`），双击 `DesktopPet.exe`。

数据都在 `%APPDATA%\DesktopPet\`，卸载不删。
