# 本地模型与离线部署

> 2026-10-18 建立。用户要求：「可离线的本地模型标上下载地址写进文档里面」。
>
> 这份 doc 只回答一件事：**哪些能力能完全离线跑、模型从哪下、下完放哪、配置怎么改**。
> 打包/分发相关的排除规则见 `docs/进度交接.md` 的「打包」待办。

## 一、总表（先看这个）

| 能力 | 本地方案 | 模型 / 组件 | 体积 | 放哪 | 配置键 |
|---|---|---|---|---|---|
| 语音识别 ASR | faster-whisper（CTranslate2） | `mobiuslabsgmbh/faster-whisper-large-v3-turbo`（默认） | ~1.6 GB | `apps/desktop/pet-data/asr-models/` | `providers.asr.provider: local` + `model` |
| 语音识别（小模型） | 同上 | `Systran/faster-whisper-small` / `-base` / `-tiny` / `-medium` | 75 MB ~ 1.5 GB | 同上 | 同上 |
| 语义记忆（检索） | bge-small-zh-v1.5（ONNX） | `bge-small-zh-v1.5`（onnxruntime 推理） | ~90 MB | `apps/desktop/pet-data/models/bge-small-zh-v1.5/` | `memory.embedding: local` |
| 语音合成 TTS | Windows SAPI（系统内置，离线） | 系统自带语音（如 慧慧/晓晓） | 0 | 无 | `providers.tts.provider: sapi` |
| 语音合成（可选） | CosyVoice2 本地部署 | `iic/CosyVoice2-0.5B` | ~2 GB+ | 自己起服务 | 走 `openai` 兼容端点 |
| 大脑 LLM | Ollama / llama.cpp / LM Studio | 如 `qwen2.5:7b-instruct`、GGUF | 4~8 GB | 各自工具目录 | `providers.brain.named.local`（见 §五） |
| 联网搜索 | **没有本地方案**（设计上就是联网） | — | — | — | 关掉即可 |

> 一句话：**关掉联网 + ASR 用 local + TTS 用 sapi + 大脑指本机 Ollama
> = 整个程序完全离线**（除了首次下模型）。

## 二、语音识别（ASR）

### 2.1 下载地址

HuggingFace（官方）：

```
large-v3-turbo（默认，推荐）
  https://huggingface.co/mobiuslabsgmbh/faster-whisper-large-v3-turbo

small / base / tiny / medium
  https://huggingface.co/Systran/faster-whisper-small
  https://huggingface.co/Systran/faster-whisper-base
  https://huggingface.co/Systran/faster-whisper-tiny
  https://huggingface.co/Systran/faster-whisper-medium
```

国内镜像（HuggingFace 直连不通时用这个，域名换一下即可）：

```
https://hf-mirror.com/mobiuslabsgmbh/faster-whisper-large-v3-turbo
https://hf-mirror.com/Systran/faster-whisper-small
```

> ⚠️ 2026-10-18 记录：本机直连 huggingface.co 失败（`fetch failed`），
> hf-mirror 可用。下载时设 `HF_ENDPOINT` 即可。

### 2.2 下完放哪

程序用的是 **HuggingFace 缓存目录格式**（不是普通文件夹）：

```
apps/desktop/pet-data/asr-models/
  models--mobiuslabsgmbh--faster-whisper-large-v3-turbo/
    refs/main
    snapshots/<commit>/model.bin, config.json, tokenizer.json, vocabulary.txt ...
```

命名规则是 `models--<org>--<name>`（斜杠换双横线）。**手放的时候必须按这个格式**，
否则程序会认为"还没下载过"，然后**真去联网下载**（`voice.py` 里有这条降级路径）。

### 2.3 什么时候会用到

```yaml
providers:
  asr:
    provider: 'local'          # 或 cloud（云端 API，语音会上传）
    model: 'large-v3-turbo'
```

程序启动时会打一行能力报告：

```
能力报告：大脑=云端（deepseek-flash） 语音识别=本地 语音合成=云端 大模型=会加载（本地 ASR）
```

看到「语音识别=本地」就说明模型被真正加载了。

### 2.4 小模型怎么选（实测结论，别乱调小）

| 模型 | 显存 | 2.3s 音频 | 中文质量 |
|---|---|---|---|
| tiny | 0.4 GB | 125 ms | ❌ `桌面宠物` → `桌面重物` |
| small | 0.9 GB | 187 ms | ⚠️ 偶尔错字，输出繁体 |
| medium | 1.5 GB | 250 ms | ✅ 但输出繁体 |
| **large-v3-turbo** | **1.6 GB** | **297 ms** | ✅ **最好，且简体** |

## 四、语音合成（TTS）

### 4.1 完全离线：Windows SAPI（系统内置）

```
providers:
  tts:
    provider: 'sapi'
```

不需要下载任何东西，用的是 Windows 自带语音。缺点：音色少、机械感强。

### 4.2 免费在线：edge-tts（默认，需联网）

```
providers:
  tts:
    provider: 'edge'
    voice: 'zh-CN-XiaoxiaoNeural'
```

> ⚠️ 名字里带 "free" 但**仍然联网**：文本会发到微软的服务器。

### 4.3 本地部署 CosyVoice2（想离线又要好听）

```
官方代码
  https://github.com/FunAudioLLM/CosyVoice
模型
  https://modelscope.cn/models/iic/CosyVoice2-0.5B
  https://huggingface.co/FunAudioLLM/CosyVoice2-0.5B
```

它需要自己起一个 OpenAI 兼容的 `/audio/speech` 服务，然后在设置里把
「合成方式」选云端、接口地址填本机地址（例如 `http://127.0.0.1:9880/v1`），
密钥随便填（本地服务不校验）。

## 五、大脑 LLM（本地）

### 5.1 Ollama（最省事）

```
下载
  https://ollama.com/download
模型库
  https://ollama.com/library/qwen2.5
  https://registry.ollama.com/library/qwen2.5:7b
```

装好后：

```bash
ollama pull qwen2.5:7b
ollama serve          # 默认 http://127.0.0.1:11434
```

程序端配置（`config/persona.yaml`）：

```yaml
providers:
  brain:
    provider: openai
    named:
      local:
        base_url: http://127.0.0.1:11434/v1
        model: qwen2.5:7b
    active: local
```

或直接用设置页：**AI 与对话 → 运行位置 → 本地模型**（会自动填地址）。

> 本机端点（127.0.0.1 / localhost）**不需要 API 密钥** ——
> 见 `brains/openai_compat.py` 的 `_is_local_url`。

### 5.2 llama.cpp / LM Studio（想更可控）

```
llama.cpp   https://github.com/ggml-org/llama.cpp
LM Studio   https://lmstudio.ai
GGUF 模型   https://huggingface.co/Qwen/Qwen2.5-7B-Instruct-GGUF
            https://huggingface.co/models?search=gguf
```

它们的 OpenAI 兼容端点一般也是 `http://127.0.0.1:xxxx/v1`，配置方式同 Ollama。

## 六、完全离线的检查清单

```
1. providers.asr.provider       = local      （模型已在 pet-data/asr-models）
2. providers.tts.provider       = sapi       （或本地 CosyVoice2 端点）
3. providers.brain.active       = 本机那个    （base_url 指向 127.0.0.1）
4. tools.web_search_mode        = off        （右键菜单 → 关闭联网搜索）
5. providers.vision.enabled     = false      （看屏幕会调云端视觉模型）
6. 截图对话（Ctrl+Alt+S）       = 不用        （同样调云端）
7. memory.embedding             = local
```

满足这 7 条后，断网也能正常聊天、记事、说话。

> 验证办法：断网 → 重启 → 看 `main.log` 的能力报告 + 随便聊一句。
> 如果还有请求失败，看日志里是哪个 `provider` 在往外发。

## 七、手机能跑吗（2026-10-18 回答）

**不能。** 现在这套是 Windows 桌面程序：

```
Electron 外壳（Windows / macOS / Linux）
  + Python sidecar（PyInstaller 冻结后是 .exe）
  + 本地模型（faster-whisper / onnxruntime，都是 x86 桌面推理）
```

手机（Android / iOS）跑不了 `.exe`，也跑不了 Electron 的主进程那一套
（文件系统、全局快捷键、多窗口、截屏 API 全不一样）。

### 三条现实路线

| 路线 | 做法 | 工作量 | 体验 |
|---|---|---|---|
| **A. 手机当客户端，电脑当大脑**（推荐先做） | 电脑跑 brain，手机浏览器/轻 App 连连看：聊天 + 语音 | 中（现有 WS 协议可用，做移动端页面 + 局域网发现） | 手机能聊，但电脑必须开着 |
| B. 手机本地跑小模型 | llama.cpp / whisper.cpp 的移动端封装（Android 可用 JNI，iOS 用 CoreML） | 大（等于重写推理层 + 模型量化） | 真离线，但慢、耗电、模型要小（1~3B） |
| C. 原生重写 | Flutter / React Native 重写外壳 + 后端服务化 | 很大 | 体验最好，成本最高 |

### 如果只想「手机上也能跟宠物说话」

最省事的是 **A**：现有 brain 就是 WebSocket + JSON（`packages/protocol` 已经定义好），
补两件事就行：

```
1. 给 brain 加一个"局域网监听"开关（默认只监听 127.0.0.1，要显式打开）
2. 写一个手机浏览器能开的极简页面（聊天气泡 + 麦克风按钮）
```

这样手机连同一个 Wi-Fi 就能用，**不需要**动桌面端的任何逻辑。

### 不推荐的路

把 Electron 硬塞进手机（如 Android 上的 Electron 壳）—— 体积大（100 MB+ 起）、
没有官方支持、截屏/快捷键/多窗口全废，属于"能启动但没法用"。

## 八、打包后的体积与内存（2026-10-18 实测）

### 8.1 实测出来的基数（这台机器，运行中）

```
Electron 运行时目录            265 MB       <- 打包必带
前端 + 主进程源码（含 assets）   55 MB
.venv 全部 site-packages     1,136 MB
  其中 nvidia（cuDNN/cuBLAS）   753 MB     <- 只有 GPU 跑 whisper 才需要
       ctranslate2              59 MB
       onnxruntime              40 MB
       numpy + numpy.libs       42 MB
       av                       67 MB       <- 打包可先试去掉（Python 侧只收 PCM 字节）
       PIL                      15 MB

运行内存（当前：云端大脑 + 本地 ASR）
   electron 10 个进程合计        995 MB
   python   4 个进程合计         421 MB
   GPU（RTX 2070 8G）已用      1,567 MiB   <- whisper turbo 吃掉的
```

磁盘现状（开发态，**不是**打包体积）：

```
apps/desktop/pet-data        3,911 MB   （asr-models 3,686 MB = 5 个模型全在）
pet-data/models                 91 MB   （bge-small-zh-v1.5）
node_modules                   846 MB   （开发依赖，不进包）
```

### 8.2 打包体积（估算，按"只带 turbo"算）

| 方案 | 安装包 | 安装后占用 | 说明 |
|---|---|---|---|
| 云端优先（模型首次下载） | **~400 MB** | ~450 MB | Electron 265 + 代码 55 + sidecar（CPU 版）压缩后约 100 |
| CPU whisper + turbo + bge | ~2.2 GB | ~2.4 GB | 不用显卡，识别慢一些 |
| GPU whisper + turbo + bge | ~2.9 GB | ~3.2 GB | 带 cuDNN/cuBLAS（+753 MB） |
| 再带 Ollama 7B 模型 | +4.7 GB | +4.7 GB | 一般**不打进包**，让用户自己 `ollama pull` |

> 模型几乎压不动（NSIS 对 bin 的压缩率 5~10%），所以"带不带模型"是体积的分水岭。

### 8.3 运行内存（按场景）

| 场景 | 内存 | 显存 | 适合 |
|---|---|---|---|
| 全云端（大脑 + ASR + TTS 都走 API） | **~1.0~1.2 GB** | 0 | 8 GB 内存的轻薄本 |
| 云端大脑 + 本地 ASR（**当前配置**） | **~1.4 GB** | ~1.5 GB | 游戏本 / 有独显 |
| 上面 + 本地大脑 3B（qwen2.5:3b） | ~3.5 GB | 2~3 GB | 16 GB 内存 |
| 上面 + 本地大脑 7B（qwen2.5:7b q4） | **~7~7.5 GB** | 4~5 GB | 16 GB 内存 + 8 GB 显存 |

> 结论：**本地大模型是内存大头**（7B 常驻 5.5~6.5 GB）。
> ASR 本地化约 +0.4 GB 内存 + 1.5 GB 显存；两者都不开，整个程序 1 GB 出头。

### 8.4 打包时要注意的三件事

```
① nvidia 那 753 MB 只有"GPU 跑 whisper"才要 —— 不带它体积小一大截，
   代价是本地识别退到 CPU（large-v3-turbo 在 CPU 上一句要 1~3 秒）
② 模型要么打进包（+1.7 GB），要么首次启动下载（推荐后者：安装包 ~400 MB）
③ pet-data（数据库/日志/模型）不能装进 Program Files，
   要放 %APPDATA% 或安装目录旁 —— 否则普通用户没有写权限
```
