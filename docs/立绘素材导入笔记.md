# 立绘素材导入：踩过的坑与正确做法

这份笔记写给"下一次导入素材"用。里面每一条都来自实际踩坑，不是推测。

## 一、抠图的本质困难

这套素材（以及在它之前的那套）有个共同点：**背景是近白，而角色身上有大量近白的部件**
（白色蕾丝发带、白围裙、白色蕾丝裙边、皮肤高光）。实测采样：

| 区域 | 亮度 lum | 饱和 sat |
|---|---|---|
| 纯背景 | ≈243 | ≈0 |
| 蕾丝发带 | ≈217 | ≈10 |
| 蕾丝高光 | ≈246 | ≈3 |
| 头发（浅色光泽） | ≈225 | ≈25 |

**背景与蕾丝在颜色上不可分。** 试过 10 组阈值组合，蕾丝被误判成背景的比例始终 ≥25%。

所以不能只靠颜色阈值，必须利用"**深色描边是屏障**"这个几何信息。

## 二、正确的算法（洪泛 + 几何）

```
1. 按颜色求出"近似背景"的像素集合（宽松判据，例如 sat<=40 且 lum>=195）
2. 从画面四边洪泛，得到"与边缘连通的背景"
3. 透明 = 洪泛到的像素；其余全部保留（原色不动）
```

**关键点（这条是反直觉的，务必记住）：**

> 被描边完全围住的白色区域，洪泛**到不了**，于是被保留为不透明。
> 这**恰好是正确的行为** —— 因为蕾丝发带上的白色凹陷、头发上的浅色光泽
> 全都是"封闭区域"。它们**必须保留**，否则蕾丝会被抠成一片空洞。

所以**不要**去"填补封闭洞"。我试过按面积阈值抠掉封闭区域，结果是：
- 面积 5542 的块 = **头发光泽**（不是背景）
- 面积 3083 的块 = 呆毛与发带之间的背景
- 两者面积同量级，**任何面积阈值都会误伤**

正确做法就是**什么都不做**，保留所有封闭区域。

## 三、尝试过并否决的方案（别重蹈覆辙）

| 方案 | 为什么否决 |
|---|---|
| 单纯调高 `bright_min` | 蕾丝误判率始终 ≥25%，分不开 |
| 对背景掩码做**闭运算**再洪泛 | `close_radius=1` 就已经把蕾丝侵蚀掉大半，`=2` 全没了。因为蕾丝与背景在掩码上**连成一片**，闭运算把整片当背景 |
| 按面积抠掉封闭块 | 见上，头发光泽块比背景块还大 |
| 按亮度区分封闭块 | 背景 230、头发光泽 225、蕾丝 230 —— 完全重叠 |
| 用眼部/脸部像素指标自动检测眨眼 | 只测到 5% 变化，测不出闭眼。**放大图肉眼一看就清楚**。教训：视觉问题不要只靠像素统计，要出图看 |

## 四、其他必须注意的点

1. **文件名通配要严格。** 用 `*.png` 会把分析产物（预览图、对比条）当成帧混进来 ——
   实测发生过：帧数 59 变 62，而且异常尺寸把"众数裁切框"算歪成 381×136，人物被压扁。
   用 `--pattern "frame_*.png"`。

2. **裁切框用"众数"而不是"并集"。** 并集会被少数几帧的大动作撑大：
   实测并集 906×574（缩放比 0.269，人物只占帧宽 40%），
   众数框 381×521（缩放比 0.468，**人物大 1.74 倍**）。

3. **水印要显式削掉。** 左上角的水印（灰黑文字）会污染"人物在哪"的检测，
   还会在缩放后糊成脏块。用 `--watermark x0,y0,x1,y1` 涂成背景色。

4. **播放器支持多行网格**（`sx = (frame % columns) * frameWidth`,
   `sy = floor(frame / columns) * frameHeight`），所以不必把 59 帧压成单行
   （单行会宽到 87000px，GPU 吃不消）。

5. **缺少某个动画状态时，回退到本素材的 idle**，不要回退到 `BUILTIN_ANIMATIONS`
   （那是程序化占位宠物的帧号，在真贴图上画出错位的一块）。

6. **单帧需要多张不同姿势的素材时，"并集裁切"是错的**（见第 2 条）。

## 五、工具

`apps/desktop/tools/import-frames.py`

```powershell
python tools\import-frames.py 帧目录 -o 输出目录 `
  --frame 256 --cols 10 --pattern "frame_*.png" `
  --watermark 0,0,268,86 --crop-mode stable --preview
```

输出 `sheet.png` + `avatar.json`，直接放进
`src/renderer/assets/avatar/default/` 即可。

生成清单时**只声明真正有素材的动画**（例如 `idle` / `blink`），
其余状态由播放器回退到 `idle` 并打日志。
