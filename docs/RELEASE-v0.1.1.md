# DesktopPet v0.1.1

桌面 AI 伴侣：透明置顶窗、会动的立绘、能打字也能说话，全部跑在本机。

> 相比 0.1.0，这一版主要在**让它更快、更少消失、更少卡住**：
> 一句回复从 11 秒降到 1 秒，联网搜索能用官方接口，全屏进出不再把它弄丢。

## 这一版改了什么

### 快

- **开 VPN 不再拖慢对话**（§一百六十九）：程序按域名分流，发往 DeepSeek / 硅基流动的
  请求**直连**，其余请求照旧走系统代理。
  实测同一句请求：`11.1 秒 → 0.85 秒`，用户能感知的首字延迟 **988ms**。
- **接入 DeepSeek 官方联网搜索**（§一百六十八）：「快速搜索」这一档现在走官方
  `/v1/tools/search`，比原来快一个数量级（`10.7s → 0.5s`）。
  ⚠️ **只有配了 DeepSeek API 密钥才能用**，没配会自动退回本地后端。

### 稳

- **「说了话它没回答」修好了**（§一百七十）：模型偶尔只思考、正文 0 字。
  现在会自动关掉思考重试一次；万一网络断了，气泡里会说一句
  「我这会儿连不上模型」，而不是留一片空白。
- **全屏进出不再弄丢姿态**（§一百七十三 / §一百七十四）：全屏时不再自动把宠物
  摆成贴边探头，退出时也不归位 —— 它待在原地不动。全屏检测还加了去抖，
  不会再因为一次误判就把姿态拉直。
  **拖拽到屏幕边缘仍然会探头**，这一条没变。
- **空回复 / 连不上时有兜底话术**，不再沉默。

### 好用

- **程序音量可调**（§一百六十七）：设置 → 语音，0~100 的滑杆，改完立刻生效。
- **名字改成「阿拾」**（§一百七十一）。

### 记忆

- **检索加了专有名词兜底**（§一百七十五）：问「银松镇那个机关怎么过」时，
  含「银松镇」的记忆现在能被捞回来（分词不认识它、向量也不敏感，原来会漏）。
- **矛盾检测**：先说「在打《银松镇》」、后说「还没开玩《银松镇》」时，
  旧那条会转成「已归档」而不是两条并存 —— 免得它说话前后矛盾。
  旧条目不删，在记忆管理里还看得见。

## ⚠️ 已知问题

- **它记不住具体的事**（这是目前最影响体验的一块）：现在提炼出来多是
  「用户认为人生岔路上的选择…」这类观点，而「喜欢曲娘、电脑壁纸是她」这种
  具体事实**根本没进记忆库**。检索再准也搜不到没写进去的东西 —— 下一版优先修。
- 未签名，SmartScreen 会拦一下（更多信息 → 仍要运行）。
- 安装包要放在纯英文路径里运行（如 `C:\Temp`）。含中文的路径 NSIS 会静默失败。
- 杀软可能误报 `resources\pet\pet.exe`，加白名单即可。

## 下载

| 文件 | 说明 |
|---|---|
| `DesktopPet-0.1.1-online-setup.exe` | 安装包 |
| `DesktopPet-0.1.1-online-portable.zip` | 绿色包，解压即用 |

**不发离线版**：1.55 GB 的语音模型不跟着包走。要离线语音，
设置 → 语音 里有下载地址（`hf-mirror.com`），下完放进提示目录即可。

校验：`Get-FileHash .\DesktopPet-0.1.1-online-setup.exe -Algorithm SHA256`

## 安装

```powershell
copy .\DesktopPet-0.1.1-online-setup.exe C:\Temp\setup.exe
C:\Temp\setup.exe
```

默认装到 `%LOCALAPPDATA%\Programs\DesktopPet`，不需要管理员权限。
绿色版解压到**可写**目录（别放 `C:\Program Files`），双击 `DesktopPet.exe`。

数据都在 `%APPDATA%\DesktopPet\`，卸载不删。
