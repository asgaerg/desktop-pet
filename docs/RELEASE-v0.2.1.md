# DesktopPet v0.2.1

桌面 AI 伴侣：透明置顶窗、会动的立绘、能打字也能说话，全部跑在本机。

> 相比 0.2.0，这是一版**修 bug 的补丁**：她之前会沉默、会把上周的事说成明天、
> 还会话说一半就断。根因都在「时间」和「说话链路」上，现在都修掉了。

## 这一版修了什么

### 「它不说话」——三个叠加的 bug

0.2.0 之后她经常一整天不出声，查下来是**三个独立问题叠在一起**：

- **开口被截图拦掉了**：判断"要不要让给截图"的那行代码把返回值
  （一个「能不能截」＋「为什么不能」的组合）直接当成了"是/否"用。
  那个组合永远算"真"，于是**每一次开口都被拦**，而截图那边又因为
  「安静/无聊档不截图」从不真的执行 —— 决定开口、让给截图、截图不截、
  什么都没发生。
- **状态变了但阈值没变**：她切到「无聊」之后，控制"多久开口一次"的那个
  参数还停在「安静」档（阈值 0.967，几乎不可能达到）。
  手动切换时两个都更新了，**自动切换时漏了一个**。
- **精力只减不增**：挂机 6 小时精力归零，然后因为「安静状态粘滞」永远出不来。
  现在安静时会慢慢回血（20 分钟回到 0.4、50 分钟回满），回满后自动转「无聊」。

### 「她话说到一半就断」

记忆里有一条 `诶，中午了，光把桌面照得发` —— 后面没了。

- **预算不够**：自主发言的 token 上限是 220，而思考模式下**推理和正文共用**
  这个预算。推理吃掉一百多，正文只剩十几个字，正好卡在"说得出一半"。
  现在提到 400（和正常回复一致）。
- **截断没被识别**：原来的逻辑只处理"截到**空**"，"截到**一半**"会被当成
  完整回复存下来，全程不报错。现在会标记并记警告。

### 「时间观念停在很久以前」

她说「那个新版本明天开」，而那件事其实是**上周**说的。

- **对话历史里没有时间**：历史是直接作为聊天记录发过去的，几十条里
  一个字的时间信息都没有，模型分不清哪条是昨天、哪条是三天前。
  现在**跨天处会标日期**（`〔今天〕`「〔6 天前〕」），同一天只标一次。
- **提示词加了三条硬约束**：
  1. 聊天记录里的时间都是**过去**，不是此刻；
  2. 版本号、进度这类**会变的信息**以最新消息为准，不确定就问，别拿旧消息硬套；
  3. 训练数据的截止日期不是现在。
- **时段划错**：13:45 被判成"中午"（原来 12–14 点都算中午）。现在
  中午只覆盖 11:00–13:00。

## ⚠️ 已知问题

- **探头旋转时仍有轻微下沉**（旧病）。这套画布 + 窗口的方案有上限，
  要序列帧动画才能根治（记在文档 §一百八十二）。
- **好奇搜索会花 API 额度**（每轮都调模型判断"还缺什么"）。
- 未签名，SmartScreen 会拦一下（更多信息 → 仍要运行）。
- 安装包要放在纯英文路径里运行（如 `C:\Temp`）。含中文的路径 NSIS 会静默失败。
- 杀软可能误报 `resources\pet\pet.exe`，加白名单即可。

## 下载

| 文件 | 说明 |
|---|---|
| `DesktopPet-0.2.1-online-setup.exe` | 安装包 |
| `DesktopPet-0.2.1-online-portable.zip` | 绿色包，解压即用 |

**不发离线版**：1.55 GB 的语音模型不跟着包走。要离线语音，
设置 → 语音 里有下载地址（`hf-mirror.com`），下完放进提示目录即可。

校验：`Get-FileHash .\DesktopPet-0.2.1-online-setup.exe -Algorithm SHA256`

## 安装

```powershell
copy .\DesktopPet-0.2.1-online-setup.exe C:\Temp\setup.exe
C:\Temp\setup.exe
```

默认装到 `%LOCALAPPDATA%\Programs\DesktopPet`，不需要管理员权限。
绿色版解压到**可写**目录（别放 `C:\Program Files`），双击 `DesktopPet.exe`。

数据都在 `%APPDATA%\DesktopPet\`，卸载不删。
