# v0.2.4 — 宠物会自己看书了

**发布日期**：2026-11-02

这一版的核心是**小说阅读**：宠物可以自己搜索小说、下载章节、读完之后跟你聊。
另外把「安静」档做成了真正的静音，以及修掉一批"测试全绿但功能不对"的问题。

---

## 一、小说阅读（这一版最大的新功能）

用户原话：

> 「自己选一本书读，有时候会换着读，有时候会读很多章，比如一次几十章几万字。」

所以阅读**不是定时抓一章**，而是给模型两个工具让它自己决定：

| 工具 | 作用 |
|---|---|
| `search_book` | 在书源里搜一本书（只搜不下载） |
| `read_book` | 读某本书的若干章（1~50），接着上次的进度 |
| `list_books` | 看本地读过哪些书、各自读到第几章 |

### 书源

内置 3 个实测可用的免费书源：

```
新笔趣阁     https://www.xbqg777.com/
思兔阅读     https://www.sto66.com/
阅读库       http://www.yeudusk.com/     ← 杰奇CMS，配置能通用到同类站
```

书源配置在 `config/book-sources.yaml`，加新源不用改代码。
`config/book-sources.example.yaml` 里有完整注释（含每个站踩过的坑）。

### 对话里也能用

> 「你去网上搜搜，看看希伯尼战记，这个好看」

以前它调 `web_search`（搜网页摘要），现在会调 `read_book` **真的去读正文**。
读完之后那一轮能讲具体情节，而不是空泛地说「这本书不错」。

### 读到哪存哪

按章节追加到 `pet-books/<书名>.txt`，每章带下载时间戳：

```
《诡秘之主》
来源：新笔趣阁
开始：2026-10-31 19:53:50

<!-- chapter:3 -->
────────────────────────────────────
第3章  第一章 绯红
下载于 2026-10-31 19:53:50
────────────────────────────────────

痛！
好痛！
```

进度存在文件本身（`<!-- chapter:N -->` 标记），不另存状态文件 ——
你手动删了 txt，它就从第一章重新开始，不会出现"文件没了但程序以为读到第 50 章"。

### 阅读历史进记忆

读过的书会写进**原文记忆**并按相关度参与检索。文本形如：

```
（我读了书《夜玄》——我自己找的）
第三章 一体双魄，药师俯首（全书第 3 章）
当夜玄、赵玉龙赶到玄冰洞府的时候…
```

开头那句让它分得清「我读过」和「我跟你说过」——
不会突然说「我上次跟你提过这本书」。

## 二、状态栏显示「看书中」

> 「状态栏要能在宠物自己搜书看的时候显示看书中，
> 这样我就知道她去看书了而不是发呆。」

新增第六档状态，**橙色**：

| 绿 | 蓝 | 紫 | 青 | **橙** | 红 |
|---|---|---|---|---|---|
| 空闲 | 搜索 | 思考 | 说话 | **看书** | 异常 |

不复用「联网搜索中」的原因：那一档的语义是"查一下就回来"（几秒），
而读书要几十秒。混用会让人以为卡住了 —— 正是你要避免的"以为她发呆"。

状态条还会显示在读哪本（「夜玄 2章」）。

## 三、「安静」档变成真正的静音

> 「状态调节现在调到安静时，将指数调低，让它要自然增长30分钟才回到无聊，
> 这样变相的能让用户安静，然后是安静状态下不主动说话，不触发任何事件，
> 安静30分钟后，转到无聊后才开始计算用户不予宠物聊天的计时。」

四条都做了：

**① 恢复正好 30 分钟**

精力恢复速率从 0.02/分 调到 0.015/分。
从安静门槛 0.4 到回满门槛 0.85，原来 22.5 分钟，现在**正好 30 分钟**。

**② 不主动说话**

**③ 不触发任何事件**

**④ 安静期间不计「多久没聊天」**

第 ④ 条容易被忽略但很重要：不这么做的话，你点安静 → 30 分钟后转无聊 →
但"多久没聊天"已经是 30 分钟了 → 立刻又满足"30分钟没聊天" → 两条规则打架。

而且语义也不对：你在安静档待的 30 分钟**不该算作"你冷落了我"**，
是你主动让它休息的。现在计时从**转无聊那一刻**重新开始。

菜单文案也跟着改了：

```
安静 · 注意力在你身上，不截图
        ↓
安静 · 切换状态后，30分钟后变为无聊
```

## 四、模块调整

「小说阅读」成为一个可开关的模块（设置 → 模块）：

```
删  立绘动画      sprite
删  窗口/气泡     ui.windows
加  小说阅读      reading
```

关掉「小说阅读」后，自主行为里只剩小黑盒杂谈这类轻事件。

小说 7 : 小黑盒杂谈 3 的权重比例（你指定的）：
关掉小说阅读模块后，`reading` 事件在**抽取阶段**就被排除，
自然只剩杂谈。

## 五、修掉的问题

### 会读错书（严重）

原来代码里有个兜底：

```python
title, url = next((b for b in books if query in b[0]), books[0])
```

搜不到匹配就随便拿第一本。实测后果：让它读《夜玄》，
新笔趣阁搜「夜玄」返回一堆带"玄"字的无关书，一本都不含「夜玄」，
于是落盘的是《让你御兽，你融合斩魄刀？》—— 而日志显示"读了 3 章"。

**看起来完全正常，只是读错了书。** 现在匹配不上就换源，宁可读不到。

### 前两章消失

两个地方都硬编码跳过前两章（因为新笔趣阁第 1 章叫「版权信息」）。
但思兔阅读的《天官赐邪》第 1、2 章是正常正文，被一起跳掉了。

现在改成**按内容判断**：空章/版权页跳过，正文照读，重复条目去重。

已经落盘的 5 本书也修好了（真缺的补回来，编号错位的重编号）。

### 记忆里是半截话

> 「记忆里面最新一条是没说完话吗」

根因是阅读回调给的是**每章 100 字的摘要**，不是正文。
现在读完整正文（363 字 -> 12871 字），并且截断落在句子边界上。

### 阅读库书源的搜索

页面 JS 里写 `<input name="searchkey">`，但服务端**只认 `q`**。
按页面上的参数名试了三轮全是 0 条，差点判定"这站搜索关了"。

## 已知限制

· **番茄小说抓不了**：正文接口返回 200 但 0 字节，
  需要字节跳动 App 级签名（`x-argus`/`x-ladon`）+ CM 通道解密。技术上做得到但工作量大。
· **免费书源寿命短**：失效是常态，抓不到会安静地换源，不会打扰你。
· **自签名证书对陌生人无效**：这是证书体系决定的，不是配置问题。
  推荐下载**绿色版**（`-portable.zip`）—— 不走安装器那轮签名检查。
