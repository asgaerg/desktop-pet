# v0.2.3 — 语音可靠性 + 代码签名

**发布日期**：2026-10-31

这一版没有新功能，主要是**修可靠性**和**把签名补上**。

---

## 一、代码签名（这一版最重要的变化）

之前**所有版本**（0.1.0 ~ 0.2.2）都是未签名的，所以每次双击都弹「未知发布者」。

从 0.2.3 起，安装包用自己的自签名证书签过（Authenticode / SHA256 / 带时间戳）。

| 场景 | 效果 |
|---|---|
| 你本机（已装证书） | ✅ 双击**无任何提示** |
| 朋友（照 `说明.txt` 装一次证书） | ✅ 之后所有版本都无提示，**5 年内有效** |
| 陌生人第一次下载 | ❌ 仍会弹——自签名的根不在微软信任列表里 |

> ⚠️ **自签名对陌生人无效**，这是证书体系决定的，不是配置问题。
> 要彻底解决只能买 EV 代码签名证书（约 2500~4000 元/年 + 企业资质 + 硬件 U 盾）。

**另一个更省事的办法**：用**绿色包**（`*-portable.zip`）。zip 不走安装器
那一轮签名检查，实测是最不容易被拦的分发方式 —— 所以这一版**推荐下载绿色包**。

### 时间戳很重要

签名时带了 `/tr http://timestamp.digicert.com`。没有它的话，证书 5 年后过期，
**已签的包会一起失效**；带上之后，哪怕证书过期，当时签的包永远有效。

## 二、语音识别：VAD 换成神经网络

**这是这一版体验提升最大的地方。**

之前用能量 + 过零率判断「有没有人在说话」。在风扇噪声环境下它彻底失灵：

· 阈值调高 → 听不见你说话（噪声底被风扇抬到 0.085、阈值 0.17，
  而人声只有 0.09~0.13，全部判成静音）
· 阈值调低 → 风扇被当成说话，Whisper 在噪声上疯狂幻听：
  ```
  语音识别（1.30s）：下班 拜拜
  语音识别（0.96s）：我爱你
  语音识别（1.34s）：应该是我妈妈
  ```

根因：**能量和过零率根本不足以区分「人在说话」和「风扇在转」**——两者都是
低频、都有能量起伏。调参只是在两种失败之间来回。

现在换成 **silero v6 神经网络 VAD**，实测区分度：

| 信号 | 判为语音 |
|---|---|
| 真实语音 | 98.7% |
| 风扇噪声 0.030 | **0%** |
| 风扇噪声 0.080 | **0%** |
| 安静 | 0% |

**零新依赖**——`onnxruntime` 和模型本来就随 faster-whisper 装好了。CPU 约 1% 单核。

**对「按住说话」同样有效**：以前风扇噪声会让 PTT 也误判。

## 三、按住说话：句首不再被切掉

端点检测要连续 3 帧确认是语音才开始录，这之前的起音全被丢掉。实际表现：

```
说「你好世界」→ 识别成「好世界」
```

加了 300ms **预录缓冲**，判到说话时把之前那段一起带上。

## 四、噪声底改用最小统计

```
噪声底 := 最近 6 秒里最安静那一帧的能量
```

旧方案「只在判为静音时更新」有个死锁：阈值一旦低于噪声，噪声永远是「语音」，
噪声底就永远不更新。新定义**根本不看判定结果**，所以没有自锁回路。

冒烟实测：

```
风扇噪声 0.030 —— 收敛后 0 帧误判
用户说话 0.130 —— 48/50 帧被听到
环境变安静      —— 噪声底回落到 0.0036
```

## 五、唤醒词模式：**已停用**（置灰）

这一版做了唤醒词模式（全屏游戏时唯一可用的触发方式，因为 ACE 反作弊会拦截
所有键盘钩子），链路是通的：

```
语音识别（1.70s）：来说说话吧阿识
唤醒词命中「来说说话吧」-> 实际内容：阿识
以语音输入发起对话：阿识
```

但**可靠性完全押在 ASR 的识别率上**，而在这台机器上不够。同一个「阿拾」
被听成过七种写法：阿诗 / 阿石 / 阿时 / 阿十 / 八十 / 阿蛇 / 阿辞。

**结论：识别率没上来之前不该暴露给用户。** 所以菜单里那一项置灰
（`唤醒词 ·未实现（识别率不够）`），配置锁在按键模式。
代码和测试都保留，将来换更好的 ASR 可以直接打开。
