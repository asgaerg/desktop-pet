# DesktopPet v0.2.0

桌面 AI 伴侣：透明置顶窗、会动的立绘、能打字也能说话，全部跑在本机。

> 相比 0.1.2，这一版是**主观层重做**：
> 「活泼度滑杆」变成了四个真正的**状态**，她开始有自己的事要做 ——
> 会自己去查东西、会催你开联网、会一本正经地说胡话逗你。

## 这一版改了什么

### 状态：从滑杆到状态机

以前"活泼度"是一个 0~1 的滑杆，决定她多久开口一次。现在它变成
**四个离散状态**，由她自己按情况切换：

| 状态 | 什么时候 | 表现 |
|---|---|---|
| **安静** | 精力低于 0.4 | 不想说话也不想动，你说话她就应着 |
| **无聊** | 你 30 分钟没聊天 | 想找点事做但没目标，会发呆 |
| **好奇** | 随机事件 / 你手动切 | 对某个东西想知道更多，会自己去查 |
| **自言自语** | 随机事件 | 沉浸在念头里，说给自己听 |

两条值得说的规则：

- **精力低于 0.4 会转安静，而且"粘滞"** —— 精力回升了也不会自动离开。
  累过之后就算缓过来，也还是想安静待着。只有你手动切、或者有事件，才能出去。
- **有事在做时，精力再低也不打断** —— 看书看到一半不会突然睡着。

### 好奇：她开始自己查东西

这是这一版最大的一块。好奇状态下：

- **联网开着** → 她自己搜，而且是**连串搜**。
  比如搜「2012 末日预言」发现只知道有这回事、不知道谁说的，
  就带着这个缺口再搜"是谁提出的"。最多 5 轮，补齐就停。
- **联网关着** → 她会来**催你**：撒娇、讲道理、装可怜、画大饼……
  共 10 次，每次间隔随机（7~60 秒）。10 次还没成，她就失去耐心，回无聊去。

**注意力决定她去干嘛**：

```
好奇 + 注意力在她自己  -> 自己查资料
好奇 + 注意力在你身上  -> 截图看你干嘛 / 一本正经说胡话逗你
```

注意力越高，越可能走"自己查"；一半一半时各 50%。不是硬性切换。

### 胡言乱语

她会突然说「意大利面拌 42 号混凝土」「面包树可解宇宙大爆炸」这种
**荒诞但一本正经**的话来吸引你注意。还会用颜文字和文字小图。

⚠️ **这一项不可关闭** —— 是设计的一部分，不是 bug。

### 语言表达层：可调的说话方式

新增一组**和情绪并列**的旋钮（设置 → 人格提示词）：

| 旋钮 | 管什么 |
|---|---|
| **修辞倾向** | 比喻、拟人、通感的密度 |
| **文化表达** | 古诗、成语、谚语 |
| **词汇能力** | 用词丰富度（0 = 大白话） |
| **温度·关心** | 冷淡 ↔ 温热，会不会主动留意你的处境 |

全部 0~1，**0.5 是中性**（不额外干预）。默认配置不给提示词增加任何内容 ——
不会因为加了这一层就让你的宠物突然变了说话风格。

**亲近度会自动抬高温度**：养得越久，她说话越暖。但那个偏移不写回你的设定值。

### 最高条例：她怎么想事情

新增三条**不分优先级**的思考约束，写在提示词里，**你可以随便改**：

```
1. 根据主观层调节自身状态。
2. 对没有明显记忆的知识拥有新鲜感。
3. 对信息不保持一味的肯定，要随时保留其他可能的概率。
```

第三条是**反谄媚**条款 —— 不把你说的话、或搜到的东西当成既定事实，
心里留着"也可能不是这样"。

⚠️ 设置页里这一块**带常驻警告**：这几条不是普通设置，
重要性不亚于定义她的感受与思维方式。改坏了她的判断会变得很怪，
而且你多半不会记得是这里改的。所以有一键「恢复默认」。

### 情绪与亲近度

- **心情初值 0.3，回归速度放慢到 3%/分钟**（原来 8%，10 分钟就抹平一次情绪）
- **「被打扰」**：她正沉浸在自己世界里时你说话，心情会掉 ——
  越专注掉得越多（最多 0.2）。但多聊几句就好了，注意力被拉过去后自己回升
- **亲近度现在会衰减了**（按自身比例 3%/分钟，原来只增不减），
  也会自动抬高说话温度

### 架构：事件统一成模块

情绪/状态相关的事情原来散在各处，每个新功能都要自己写"我现在能不能做"。
现在统一成一个事件模块：

- **同一时间只允许一个事件**（单占位槽）。加新事件零改动，
  不用再写"防止冲突"的代码
- 状态切换的三条规则也从代码里的 if 链变成了**可读的数据**
- 事件超时会自动释放（不会永久卡死）

## ⚠️ 已知问题

- **探头旋转时仍有轻微下沉**（旧病）。结论记在文档 §一百八十二：
  这套 H5 画布 + 窗口的方案有上限，要序列帧动画才能根治。
- **好奇搜索会花 API 额度**（每轮都调模型判断"还缺什么"）。
  建议在设置里配好额度心里有数。
- 未签名，SmartScreen 会拦一下（更多信息 → 仍要运行）。
- 安装包要放在纯英文路径里运行（如 `C:\Temp`）。含中文的路径 NSIS 会静默失败。
- 杀软可能误报 `resources\pet\pet.exe`，加白名单即可。

## 下载

| 文件 | 说明 |
|---|---|
| `DesktopPet-0.2.0-online-setup.exe` | 安装包 |
| `DesktopPet-0.2.0-online-portable.zip` | 绿色包，解压即用 |

**不发离线版**：1.55 GB 的语音模型不跟着包走。要离线语音，
设置 → 语音 里有下载地址（`hf-mirror.com`），下完放进提示目录即可。

校验：`Get-FileHash .\DesktopPet-0.2.0-online-setup.exe -Algorithm SHA256`

## 安装

```powershell
copy .\DesktopPet-0.2.0-online-setup.exe C:\Temp\setup.exe
C:\Temp\setup.exe
```

默认装到 `%LOCALAPPDATA%\Programs\DesktopPet`，不需要管理员权限。
绿色版解压到**可写**目录（别放 `C:\Program Files`），双击 `DesktopPet.exe`。

数据都在 `%APPDATA%\DesktopPet\`，卸载不删。
