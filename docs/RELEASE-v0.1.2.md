# DesktopPet v0.1.2

桌面 AI 伴侣：透明置顶窗、会动的立绘、能打字也能说话，全部跑在本机。

> 相比 0.1.1，这一版主要在**让它记住真正有用的事，把这个"记忆"摊开给你看，
> 并且修掉拖拽/探头那一串位置不一致的老毛病**。

## 这一版改了什么

### 记忆

- **提炼提示词加了「记物不记话」**（§一百七十六）：以前抽出来的多是
  「用户认为人生岔路上的选择…」这类观点，现在要求记**具体的东西** ——
  「用户喜欢《明日方舟》的曲娘，电脑壁纸是她」这种才收；
  明说抽不出具体事实就**输出空行**，宁缺毋滥（一次最多 3 条）。
- **顺手挖出一个解析器 bug，比提示词本身更严重**（§一百七十六）：
  提炼结果是 markdown，而解析时把「## 🔴 第二重要：记物不记话」这类**标题行当成了脏行丢掉**，
  于是模型最当真的那条要求反而被吞了。现在块内容改成按行号回原文取，
  空行、`#` 行都保留。
- **泛问句兜底**（§一百七十七）：「我在玩什么游戏」这种问句召回 0 条 ——
  问句太泛、抽不出专有名词，向量也不像。现在落空时回退到最近记忆，
  并加了闸门（阈值比"落空"严得多，避免乱塞）。
- **重要性打分做成工具**（§一百七十八）：`tools/score-memory.py`，
  四种模式（看分布 / 给文本打分 / 写回库 / 对比权重方案）。用规则不用模型 —— 可复现、可调结构。
- **清掉 15 条"纯聊天记录"**（§一百七十九）：按"是不是对话过程"而不是"分数低于某值"来判，
  避免误伤真正的事实。
- **记忆管理四个界面问题**（§一百八十）：
  - 检索层的时间列以前是空的（一个类型错误），现在显示真实时间；
  - **珍藏记忆和"固定注入"解耦** —— 那两个本来就是不同功能，珍藏不再显示固定注入列；
  - 固定注入改为显示时间；
  - **检索层能显示玩伴自己的事了**：不顺着用户说、而是自己讲出「我要叫阿拾」
    这类，以前根本抽不出来。

### 拖拽 / 探头

- **拖宠物不同部位，缩进去的距离不一样**（§一百八十一）：退回探头后缓存被
  「探头尺寸下的窗口」污染（`23` 忽然变成 `42`），把居中值算歪了。已加尺寸判据。
- **左右两边不一致**：判定用的是"探头姿态"的偏移（被 ±68 的平移带偏），
  于是右边要拖得远得多才触发（实测中位差 **92px**）。现在判定改用静止态缓存。
  另外左右**露出量确实差 11px**（立绘轮廓不对称），贴右加了一份按比例的轮廓补偿。
- **靠边闪现**：上一版为了拿干净偏移，进探头时先缩回常态尺寸再撑开，一进就跳两次。
  已撤销。
- **设置里「探头时的平移距离」以前根本没生效** —— 那段代码被一个没闭合的注释吞掉了，
  输入的数值一个都没存下来（磁盘上一直是 68）。现在能正常调、能记住。

### 情绪

- **表情终于跟着情绪走**：后端早就算好了离散标签（困 / 兴奋 / 开心 / 不爽 / 好奇），
  但没传给渲染层，立绘只能自己从心情值猜 —— 于是 prompt 里写着「你现在有点不爽」、
  它还在笑。现在标签随情绪快照一起下发，立绘照着播；
  同一条情绪广播不会反复打断正在播的表情。

## ⚠️ 已知问题

- **探头旋转时会有轻微的下沉**（旧病，这一版没能消除）。
  根因是"用像素扫描出的实测值去近似几何量"，被 45° 放大后就会看出来。
  结论已记进文档 §一百八十二：**这套 H5 画布 + 窗口的方案有上限**，
  以后要用序列帧动画重做才能真正消掉。
- **记忆还偏保守**：宁缺毋滥之后，有些该记的会被漏掉。下一版会调这条线。
- 未签名，SmartScreen 会拦一下（更多信息 → 仍要运行）。
- 安装包要放在纯英文路径里运行（如 `C:\Temp`）。含中文的路径 NSIS 会静默失败。
- 杀软可能误报 `resources\pet\pet.exe`，加白名单即可。

## 下载

| 文件 | 说明 |
|---|---|
| `DesktopPet-0.1.2-online-setup.exe` | 安装包 |
| `DesktopPet-0.1.2-online-portable.zip` | 绿色包，解压即用 |

**不发离线版**：1.55 GB 的语音模型不跟着包走。要离线语音，
设置 → 语音 里有下载地址（`hf-mirror.com`），下完放进提示目录即可。

校验：`Get-FileHash .\DesktopPet-0.1.2-online-setup.exe -Algorithm SHA256`

## 安装

```powershell
copy .\DesktopPet-0.1.2-online-setup.exe C:\Temp\setup.exe
C:\Temp\setup.exe
```

默认装到 `%LOCALAPPDATA%\Programs\DesktopPet`，不需要管理员权限。
绿色版解压到**可写**目录（别放 `C:\Program Files`），双击 `DesktopPet.exe`。

数据都在 `%APPDATA%\DesktopPet\`，卸载不删。
